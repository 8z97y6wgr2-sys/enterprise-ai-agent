# Agent specifications

Status: conceptual specifications; no agent implementation is included.

For each of Finance, Accounting, Marketing, Sales, Operations and Administration, define: tenant and role scope, accepted input schema, permitted data/tool access, deterministic checks, output schema, supporting evidence, approval triggers and failure behavior.

Finance and Accounting must distinguish recorded facts, calculated metrics and generated explanations. Marketing and Sales must prepare drafts without silently publishing or sending. Operations and Administration must keep state changes permissioned and auditable. Define what each agent cannot decide autonomously before granting tools.
