# Workflow design

Status: proposed workflows; no executable automation is included.

Suggested initial flow: user supplies authorized business records → validate and scope to tenant → compute deterministic summary → agent drafts explanation → user reviews evidence and proposed next steps → approved action executes → audit outcome.

Begin with a cash-flow summary or invoice exception review. Define success measures such as calculation accuracy, review time, source completeness and tenant-isolation behavior. External publication, messages, payments or accounting postings require an explicit approved action.
